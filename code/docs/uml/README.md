# UML-диаграммы для приложения к диплому

Диаграммы в формате **PlantUML** (текст), покрывающие архитектуру и логику проекта.

## Как редактировать

Каждый `.puml` — это обычный текст. Открой в любом редакторе и правь. Структура файла:

```plantuml
@startuml <название>
title <заголовок диаграммы>

skinparam ...    ' визуальные настройки (шрифт, цвета)

' ===== сущности =====
class Foo { ... }
class Bar { ... }

' ===== связи =====
Foo --> Bar : "сообщение"

@enduml
```

### Быстрый старт в VS Code (рекомендую)

1. Поставь расширение **PlantUML** (id: `jebbs.plantuml`)
2. Установи зависимости рендера:
   ```bash
   brew install graphviz openjdk
   ```
3. Открой `.puml`, нажми `Alt+D` (Option+D на Mac) — live-preview справа
4. Правишь текст — превью обновляется автоматически

### Альтернатива без установки: онлайн-редактор

Скопируй содержимое `.puml` в [PlantUML Online Server](https://www.plantuml.com/plantuml/uml/) — там же сразу скачаешь PNG/SVG.

## Как рендерить в файлы

### Установка PlantUML CLI

```bash
brew install plantuml
```

### Рендер всех диаграмм одной командой

```bash
# из корня проекта
cd docs/uml

# PNG 300 dpi (для Word)
plantuml -tpng -DPLANTUML_LIMIT_SIZE=16384 *.puml -o png/

# SVG (для LaTeX / вектор)
plantuml -tsvg *.puml -o svg/

# PDF (если стоит OpenJDK + Apache Batik)
plantuml -tpdf *.puml -o pdf/
```

Результат: `docs/uml/png/01_package.png`, `02_augmentation_pipeline.png`, ...

### Только одну диаграмму

```bash
plantuml -tpng 04_finetune_classes.puml -o png/
```

## Как вставить в Word

1. Сгенерируй PNG (см. выше)
2. В Word: **Вставка → Рисунки → Из файла** → `docs/uml/png/<имя>.png`
3. Для качественной печати: открой PNG, проверь что DPI ≥ 300 (`identify -format "%xx%y\n" 01_package.png` — должно быть `300x300`)
4. Подпись под рисунком — стиль «Подпись рисунка», нумерация автоматическая

> Если картинка получается слишком большой по высоте — увеличь параметр в `.puml`:
> `skinparam dpi 200` (по умолчанию 96; больше = плотнее текст, меньше высота).

## Как вставить в LaTeX

```latex
\begin{figure}[ht]
    \centering
    \includegraphics[width=0.95\textwidth]{docs/uml/svg/04_finetune_classes.svg}
    \caption{Диаграмма классов: ядро PEFT fine-tune}
    \label{fig:finetune-classes}
\end{figure}
```

> Для SVG в LaTeX нужен пакет `svg`:
> ```latex
> \usepackage{svg}
> \includesvg[width=0.95\textwidth]{...}
> ```
> Альтернатива: рендерить сразу в PDF (`plantuml -tpdf ...`) и подключать `\includegraphics{...pdf}` — это надёжнее с любым движком LaTeX.

## Подсказки по правке

- **Изменить заголовок** — строка `title ...` в начале файла
- **Добавить класс / шаг** — найди блок `class Foo { ... }` или `:Описание шага;` и продублируй
- **Поменять цвет** — `skinparam <ClassName>BackgroundColor #HEXCODE` сверху файла
- **Текст не помещается** — разбей через `\n` (например, `class "очень\nдлинное\nимя"`)
- **Слишком много деталей в активности** — заверни в `partition "Группа" { ... }` (визуальный блок)
- **Поменять направление стрелок (вертикаль → горизонталь)** — `left to right direction` сразу после `@startuml`

## Что показано не во всех диаграммах (намеренно)

Несколько вещей опущены, чтобы не утяжелять картинку. Если они нужны для текста диплома, добавь сам:

- **Конкретные модели аугментации** (Qwen2.5-32B-AWQ и т. п.) — упомянуты только в #02 как комментарий, можно вынести в подпись
- **Конкретный список 36 классов** — нет ни в одной (бессмысленно для UML)
- **Версии библиотек** (transformers, peft, vllm) — посмотри `requirements.txt`, если нужно для deployment-диаграммы
- **Список GPU-профилей** (T4 / L4 / A100_40 / A100_80 / H100) — в README основного проекта есть таблица, можно вставить рядом с #06

## Проверка перед сдачей

1. Открой каждую отрендеренную диаграмму в Preview / Word на 100% масштабе
2. Убедись, что весь текст читается без увеличения (если нет — увеличь `skinparam dpi 200` или разбей сложную диаграмму на две)
3. Проверь, что подписи на диаграммах согласованы с текстом главы (имена `SeqClsRunner`, названия этапов и т. п.)
